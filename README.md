# OpenDSA-Node

OpenDSA-Node is a Node.js server for the OpenDSA eTextbook system. It uses LTI 1.3 (with support for LTI 1.1) to server OpenDSA content to Learning Management Systems such as Canvas or Moodle. This repository is intended to  be run in parallel with the OpenDSA frontend driven by the containerization support found in OpenDSA-NodeStack.
